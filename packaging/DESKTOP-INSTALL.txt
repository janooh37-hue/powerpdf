PowerPDF desktop packaging feasibility artifacts — CI HARNESS ONLY

These artifacts contain a packaging test window, NOT the PowerPDF application.
They deliberately have a separate product name and installer identity. They
never publish a GitHub release. The production GUI cutover is a separate step.

Windows x64: run the setup executable. This build is unsigned; Windows Defender
SmartScreen may warn that the publisher is unknown. Verify the download's
checksum and repository provenance before choosing More info / Run anyway.
No administrator rights or separate Python, GS or Tesseract installs are needed.

macOS 13+: choose the DMG matching arm64 (Apple Silicon) or x64 (Intel), mount it,
and drag the .app to Applications. These builds are ad-hoc signed, NOT Developer
ID signed or notarized. For an independently verified download, first try
Finder right-click / Open. If macOS blocks the quarantined unsigned app, remove
quarantine from this app ONLY (do not disable Gatekeeper globally):
  xattr -dr com.apple.quarantine /Applications/PowerPDF-Packaging-Smoke.app
The source-build helpers are statically linked against their pinned libraries;
otool -L is gated to Apple system libraries only. No Homebrew installation or
Homebrew dylib paths are needed. The bundle is finally ad-hoc signed with
codesign --force --deep -s - (including arm64 nested executables).

Linux x64: Ubuntu 22.04 is the native build baseline. Mark the AppImage executable
and launch it, or use --appimage-extract-and-run if FUSE is unavailable. The .deb
installs in /opt/powerpdf-packaging-smoke with a desktop entry and PDF Open With
registration, never silently changing PDF defaults. Remove with your package
manager. A clean Ubuntu 24.04 container smoke verifies extracted AppImage launch.
Desktop display servers, printer drivers/spoolers and GPU kernel drivers remain
OS facilities; offscreen CI is not desktop/printer qualification.

CI invocation (the probe intentionally requires an output folder):
  PowerPDF-Packaging-Smoke --output /path/to/evidence
CI sets QT_QPA_PLATFORM=offscreen. PNGs show the bundled Noto Arabic font;
rendered PDF and helper/version/model evidence are written beside each PNG.

All bundles include helper/model/font licenses and corresponding-source
pointers. PowerPDF is AGPL-3.0-or-later. The application source archive and exact
Ghostscript source accompany CI artifacts; see THIRD-PARTY-NOTICES.txt.
