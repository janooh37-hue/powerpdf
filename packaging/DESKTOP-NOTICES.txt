Ghostscript: AGPL-3.0-or-later; Windows/macOS 10.08.0.
Exact source archive ghostscript-10.08.0-source.tar.xz accompanies artifacts.
https://github.com/ArtifexSoftware/ghostpdl-downloads/releases/tag/gs10080
Linux uses Ubuntu 22.04 Ghostscript 9.55.0 with Ubuntu security patches instead;
LINUX-PROVENANCE.json records exact binary versions/SHA256s, package copyright
files are in licenses/ubuntu, and LINUX-SOURCES.txt points to Ubuntu's matching
source packages. Those source packages include the corresponding patch/build
recipes, not only upstream sources. Do not substitute the 10.08 source archive
for the Ubuntu Ghostscript corresponding source.

Leptonica (BSD-2-Clause): https://github.com/DanBloomberg/leptonica/tree/1.85.0
macOS image input support is PNG (matching card OCR); libpng 1.6.47 and zlib 1.3.1
are statically linked. Other Leptonica input codecs are deliberately disabled.
All macOS source URLs and verified SHA256s are recorded in SOURCE-INPUTS.json.

PySide6 / Qt 6.8.3: LGPL-3.0 / GPL / commercial, selected Qt Widgets modules.
https://download.qt.io/archive/qt/6.8/6.8.3/single/
https://code.qt.io/pyside/pyside-setup.git/?h=v6.8.3
Shiboken6 uses the same Qt for Python release/source.
Qt/PySide shared libraries remain separate in the onedir bundle; recipients may
replace compatible libraries and run their modified copy. No EULA restricts
modification/reverse engineering for this purpose. Re-sign modified macOS copies
with codesign --force --deep -s - /path/to/app. Rebuild instructions and scripts
are included in the application source archive. No unnecessary QtWebEngine,
Qt3D, QtQuick or multimedia modules are collected.
