A complete Windows x64 install, not just the TUI executable.

Download powerpdf-<version>-windows-x64-setup.exe and run it. No Python, uv,
Ghostscript, Tesseract, fzf or PowerShell 7 installation is required. The default
install is per-user under %LOCALAPPDATA%\Programs\PowerPDF (no administrator
rights); all-users installation is optional. Open a new terminal after setup.
Unsigned installers may trigger Windows SmartScreen; verify the release origin.

Includes powerpdf, pdfsplit, pdfmerge, pdfcompress, pdfimage and pdfprint on PATH;
a Start Menu shortcut (Windows Terminal when available, normal console otherwise),
an optional desktop shortcut, Add/Remove Programs uninstall, and in-place upgrades.

Bundled external runtimes:
- Ghostscript 10.08.0: compression and Windows printing; AGPL-3.0.
- Tesseract 5.5.0 / Windows build 5.5.0.20241111: card-name OCR; Apache-2.0.
- tessdata_fast 4.1.0: English, Arabic and orientation models; Apache-2.0.
- fzf 0.74.4: interactive print/file/printer selection; MIT.

License texts and source links are installed in bin\licenses and
bin\THIRD-PARTY-NOTICES.txt. The Ghostscript corresponding-source archive is
provided as an additional release asset at no charge.

Also includes the many-cards-per-scan workflow, named cards and confirmed-only OCR
name suggestions. Originals are never overwritten by PDF processing commands.

The portable zip contains the SAME complete one-folder runtime and command shims,
but does not change PATH or create shortcuts. Extract the entire folder; do not
copy powerpdf.exe out of it. One-folder packaging retains fast startup without
one-file extraction on every launch.

The release is published only after Windows CI tests and silent-install smoke
checks pass: refreshed PATH, version, all CLIs, bundled Ghostscript/Tesseract/fzf,
English+Arabic+OSD data, upgrade and uninstall PATH cleanup. Printing smoke checks
help only; no physical printer jobs are submitted.
